# NyoNyo-Reminder---IDM-BOB
startup reminder sebagai solusi kecanduan media sosial

## 📥 Cara Memasang NyoNyo Reminder

Ikuti langkah-langkah berikut untuk memasang NyoNyo Reminder di Microsoft Edge.

### 1. Unduh NyoNyo Reminder

1. Buka halaman repositori GitHub NyoNyo Reminder.
2. Klik tombol **Code**.
3. Pilih **Download ZIP**.
4. Setelah unduhan selesai, ekstrak file ZIP ke folder yang mudah ditemukan, misalnya Desktop.

### 2. Buka Pengaturan Ekstensi Microsoft Edge

1. Buka Microsoft Edge.
2. Ketik alamat berikut pada bilah alamat:

   `edge://extensions`

3. Tekan Enter.

### 3. Aktifkan Mode Pengembang

1. Cari tombol **Developer mode** atau **Mode pengembang**.
2. Aktifkan tombol tersebut.

### 4. Pasang NyoNyo Reminder

1. Klik tombol **Load unpacked** atau **Muat tanpa paket**.
2. Cari folder NyoNyo AI yang sudah diekstrak sebelumnya.
3. Pilih folder yang berisi file `manifest.json`.
4. Klik **Select Folder** atau **Pilih Folder**.

Pastikan folder yang dipilih adalah folder utama ekstensi, bukan folder di dalamnya.

### 5. Mulai Gunakan NyoNyo Reminder

1. Klik ikon **Extensions** atau **Ekstensi** di Microsoft Edge.
2. Cari NyoNyo AI Reminder.
3. Jika ingin lebih mudah diakses, sematkan ekstensi melalui menu tersebut.
4. Buka NyoNyo AI Reminder dan gunakan fitur yang tersedia.

### 🔄 Cara Memperbarui NyoNyo Reminder

Jika tersedia versi terbaru:

1. Unduh versi terbaru dari GitHub.
2. Ekstrak file ZIP ke folder baru.
3. Buka `edge://extensions`.
4. Hapus ekstensi versi lama jika diperlukan.
5. Klik **Load unpacked** dan pilih folder versi terbaru.

**Catatan:** Jangan menghapus versi lama sebelum memastikan pengaturan atau data pengingat yang ingin dipertahankan sudah aman.

### ⚠️ Catatan Penting

- NyoNyo AI Reminder dipasang sebagai ekstensi Microsoft Edge, bukan sebagai aplikasi Windows biasa.
- Jangan menghapus folder hasil ekstraksi setelah memasang ekstensi karena Edge memuat ekstensi dari folder tersebut.
- Pastikan kamu mengunduh file hanya dari repositori GitHub resmi NyoNyo AI Reminder.
